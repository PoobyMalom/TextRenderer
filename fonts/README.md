# fonts

Put your font files (`.ttf`) here. Font files in this folder are gitignored, so each checkout supplies its own.

`demo`, `benchmark_cdt` and `make run-triangulation` look for fonts in this folder, and `demo` and `make run-triangulation` expect `JetBrainsMono-Regular.ttf` (`demo` also expects `papyrus.ttf` and `MonsieurLaDoulaise-Regular.ttf`).
